# HDD Data Refresh Tool（硬盘数据刷新工具）

> 防止机械硬盘长期存放导致的数据丢失 —— 通过安全重写全部文件刷新磁信号

> 🤖 **本项目由 DeepSeek（deepseek-v4-flash）完成编码、测试与上传**

## 为什么需要这个工具？

机械硬盘靠磁性记录数据。硬盘**长时间不通电、不读写**时，磁信号会逐渐减弱（磁畴衰减），七八年后可能出现文件损坏、读不出来。

解决办法：**把数据重新读写一遍**，磁信号就"满血复活"了。本工具安全地、可中断地、分批地刷新硬盘上的所有数据。

**只适用于机械硬盘（HDD）。** SSD、U盘、内存卡不需要也不建议这样做。

## 功能特性

- ✅ **逐文件安全重写**：读原文件 → 写临时副本 → 校验大小 → 删除原文件 → 改回原名，中断最多影响 1 个文件
- ✅ **断点续跑**：按二级目录记录进度，中断/崩溃后重跑自动跳过已完成部分
- ✅ **整体进度显示**：实时显示已完成 GB / 总 GB / 百分比（按数据量，不是按文件夹数）
- ✅ **只读文件处理**：自动处理 ReadOnly 文件（清除只读 → 重写 → 恢复属性）
- ✅ **残留恢复**：启动时自动恢复上次异常中断留下的临时文件
- ✅ **守护模式**：`guard_refresh.ps1` 自动检测任务崩溃并重启，无人值守
- ✅ **BitLocker 检测**：加密盘未解锁时明确提示
- ✅ **日志记录**：全部操作日志 + 失败文件明细

## 快速开始

### 方法一：一键 BAT（推荐）

1. 双击 `refresh_drive.bat`
2. 输入要刷新的盘符（如 `G` 或 `E`），回车
3. 等待进度完成

### 方法二：直接运行 PowerShell

```powershell
# 刷新整个盘
powershell -ExecutionPolicy Bypass -File .\refresh_drive.ps1 -Root "G:\"

# 守护模式（自动重启崩溃的任务）
powershell -ExecutionPolicy Bypass -File .\guard_refresh.ps1
```

## 文件说明

| 文件 | 作用 |
|------|------|
| `refresh_drive.ps1` | 核心脚本：逐文件重写、断点续跑、进度显示 |
| `refresh_drive.bat` | 一键入口：选择盘符后调用核心脚本 |
| `guard_refresh.ps1` | 守护脚本：每 5 分钟检查任务，崩溃自动重启 |

## 工作流程

```
启动 → 预扫描全盘总字节数
     → 遍历二级目录（跳过已完成）
     →   对每个文件：读原 → 写副本 → 校验大小 → 删原 → 改名
     → 记录目录完成状态
     → 全部完成
```

## 运行产物

| 文件 | 说明 |
|------|------|
| `refresh_state_<盘符>.txt` | 已完成目录列表（断点续跑依据） |
| `refresh_log_<盘符>.txt` | 运行日志（含失败明细） |
| `refresh_monitor_E.txt` | 守护模式心跳记录 |

> 删除对应的 state 文件 = 整盘重新刷一遍

## 注意事项

| 事项 | 说明 |
|------|------|
| ⚠️ 刷新期间**不要关机/断电** | 设计了保护，但稳妥起见建议睡前运行 |
| ⚠️ **BitLocker 加密盘必须先解锁** | 未解锁会提示无法访问 |
| ⚠️ 磁盘需留少量空闲 | 只需约 1 个最大文件的大小（逐文件处理） |
| ✅ 只占用所选盘 | 其他盘完全不受影响 |
| ✅ CPU 占用极低 | 主要是磁盘 IO，可正常使用电脑 |
| ✅ 可随时中断 | Ctrl+C 或关窗口，下次自动续跑 |

## 常见问题

**Q：能同时跑两块盘吗？**
A：不建议。机械盘多任务会来回寻道反而更慢，一块跑完再跑下一块。

**Q：多久需要刷一次？**
A：长期存放不用的机械盘，建议每 1-2 年刷一次；平时隔几个月通电读写一下更好。

**Q：能修复已损坏的硬盘吗？**
A：不能。有物理坏道/异响/掉盘的请先备份数据。本工具是预防磁信号衰减，不是维修工具。
